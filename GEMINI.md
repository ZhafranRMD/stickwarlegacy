# Guidelines & Behavioral Rules

## 1. Aturan Penyimpanan & Git (MUTLAK)
- **Perubahan Wajib Disimpan di Lokal Saja**: Segala perubahan kode, penambahan fitur, pembaruan desain, atau perbaikan bug hanya disimpan di folder lokal proyek.
- **JANGAN PUSH KE GITHUB JIKA BELUM DIINSTRUKSIKAN**: Dilarang keras melakukan perintah `git push` ke GitHub/remote repository apa pun sebelum ada perintah atau instruksi eksplisit dari pengguna.

## 2. Struktur Proyek
- Proyek lokal: Game Stick War Legacy dengan elemental skins (Api & Es), kontrol unit bintang 2X damage, dan fitur lengkap lainnya.
- Simpan perubahan di folder lokal proyek `Stick war` dan pastikan seluruh fungsionalitas berjalan secara lokal.
