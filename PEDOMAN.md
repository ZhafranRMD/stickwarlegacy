# PEDOMAN KERJA PENGEMBANGAN PROYEK (STICK WAR)

> **ATURAN MUTLAK & PEDOMAN TETAP:**
> 1. **Semua perubahan hanya disimpan di lokal**: Setiap modifikasi kode, penambahan fitur, aset, dan dokumen hanya diterapkan dan disimpan pada direktori lokal.
> 2. **DILARANG PUSH KE GITHUB JIKA BELUM DIINSTRUKSIKAN**: Jangan pernah menjalankan perintah `git push` ke GitHub atau remote repository apa pun kecuali pengguna secara eksplisit memberikan instruksi untuk melakukan push.
> 3. **Prioritaskan integritas berkas lokal**: Pastikan berkas di proyek lokal selalu sinkron, bersih, dan dapat dijalankan langsung di lingkungan lokal.
